# Idea-to-Website Generator

Drop an idea, get a complete marketing funnel.

## What You Get (Every Time)

Just message your idea and everything below is generated automatically:

| Asset | File | Description |
|-------|------|-------------|
| Audience Research | `audience.md` | Ideal buyer persona, pain points, objections |
| Offer Strategy | `offer.md` | Name, pricing, bonuses, guarantee |
| Sales Page | `sales-page.html` | Complete, styled, responsive HTML page |
| Promo Posts | `social-promotional.md` | 5 posts that sell the offer |
| Pre-Launch Posts | `social-prelaunch.md` | 5 posts that build trust (no selling) |
| Fulfillment Emails | `fulfillment-emails.md` | 2 post-purchase emails |
| Abandoned Cart Emails | `abandoned-cart-emails.md` | 4-email recovery sequence |

## How to Use

1. Open a Claude Code session in this repo
2. Type your idea (e.g., "A 6-week course teaching freelancers how to land $10k clients")
3. Everything gets generated in `generated/[your-idea-slug]/`
4. Open `sales-page.html` in your browser to preview
5. Customize the `[PLACEHOLDER]` sections with your real content

## Output Location

All generated funnels live in the `generated/` folder:

```
generated/
  6-week-10k-freelancer-course/
    audience.md
    offer.md
    sales-page.html
    social-promotional.md
    social-prelaunch.md
    fulfillment-emails.md
    abandoned-cart-emails.md
```

Each idea gets its own folder so you can generate as many as you want.
